# Pavise DX12 VRS 离屏台架结果

测试时间：2026-08-17

## 结论

本机 RTX 3090 报告支持 DX12 VRS Tier 2。对刻意构造的重像素着色负载，VRS 的 GPU 时间几乎严格按像素着色调用量缩放：

| 着色率 | 第一轮中位 GPU 时间 | 复跑中位 GPU 时间 | 相对 `1x1` 加速 |
|---|---:|---:|---:|
| `1x1` | 3.494 ms | 3.494 ms | 1.000x |
| `1x2` | 1.757 ms | 1.757 ms | 1.989x |
| `2x1` | 1.755 ms | 1.755 ms | 1.991x |
| `2x2` | 0.885 ms | 0.885 ms | 3.949x |

这证明两件事：

1. 本机硬件和驱动的 VRS 路径正常工作，减少像素着色调用确实直接减少 GPU 时间。
2. 台架只能给出像素着色阶段的理论上限，不能把 `3.949x` 当成游戏 FPS 收益。

## 条件

- GPU：NVIDIA GeForce RTX 3090，PCI `VEN_10DE / DEV_2204`
- 专用显存：24326 MB
- VRS：Tier 2，支持 Additional Shading Rates
- 离屏尺寸：1600 x 900
- 每个样本：10 次全屏重像素着色绘制
- 第一轮：每档 28 个样本
- 复跑：每档 40 个样本
- 顺序：镜像配对 `1x1 / 1x2 / 2x2 / 2x1 / 2x1 / 2x2 / 1x2 / 1x1`
- 计时：D3D12 GPU timestamp query
- 运行：Windows 子系统 EXE、无窗口、无交换链、低于正常优先级、样本之间空闲 10 ms

## 不能从本结果推出的结论

- 不能推出三角洲、CS2 或英雄联盟会获得同等比例的 FPS 提升。
- 不能解决 CPU、几何、光追、内存带宽、Shader 编译和资源加载瓶颈。
- 不能证明图形 API DLL 注入对反作弊安全。
- 不能证明在不知道 HUD、透明层和后处理语义时可以保持可接受画质。

下一阶段若继续，应在自有渲染台架加入 Tier 2 Shading Rate Image：中央 `1x1`、中环 `1x2`、外围 `2x2`，同时加入细线、文字、准星和高速运动图案，量化性能与画质损失。只有这一步通过，才值得研究图形 API 接入。
