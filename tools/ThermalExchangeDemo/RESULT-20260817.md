# Thermal Exchange Demo 实机结果（2026-08-17）

## 环境与方法

- GPU：NVIDIA GeForce RTX 3090。
- 负载：Pavise 原生屏幕外 D3D9 测试台架，2560×1440、192 次混合填充/帧、2 个 CPU 工作线程。
- 测试窗口固定在 `-32000,-32000`，全程不激活。
- GPU 压力：约 95%～100%，约 310～326 W。
- Demo 只激活复制出来的临时电源方案；结束后恢复原“高性能”方案并删除临时方案。

## 结论

这台 RTX 3090 环境没有测到可重复收益。第一轮的表面提升是热漂移假象；预热交错复验显示 85% CPU 上限约为持平到轻微倒退，GPU 频率也完全没有提高。

因此当前 Demo 只证明控制、测量与自动恢复链路可用，不支持把“跨芯片热预算交换”加入 Pavise 正式功能。若继续研究，应只在 CPU/GPU 明确共享功耗与散热预算的 Max-Q 笔记本上重新做预热后的交错实验。
