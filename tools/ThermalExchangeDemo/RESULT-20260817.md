# 热预算交换实测 2026-08-17

RTX 3090 离屏 D3D9 负载 2560x1440 GPU 跑到 95% 到 100% 310 到 326 W Demo 只激活一份临时电源方案 轮流改 CPU 最大性能状态

探索轮 100/95/90/85/90/95/100 85% 档看着 FPS +2.8% 但这一轮 GPU 从 73°C 升到 77°C 首尾两个 100% 档自己也差了 2.8% 是热漂移
