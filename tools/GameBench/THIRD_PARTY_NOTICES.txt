This document retains upstream notices for runtime/support components supplied

d408dd38eed3e5204af841bcebf70502a4dbbb8399a3a3262be55059370bc018

The build's local runtime archives include libc++, libc++abi, LLVM libunwind,
mingw-w64 startup/support, Zig compiler_rt and Zig C support. The executable's
PE import directory references Windows/UCRT system libraries; it does not
reference a separate libc++, libstdc++, libgcc or winpthreads runtime DLL.

into the Pavise distribution by this package.
