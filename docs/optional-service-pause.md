# 游戏期间暂停非必要系统服务

入口：**优化策略 → 会话附加 → 暂停非必要系统服务**。默认关闭，各性能预设不会自动打开；逐游戏配置的“系统环境”分组可单独覆盖。全局设置键为 `GmPauseServices`。

## 范围与时机

沿用会话环境策略的入局 20 秒延迟，由现有后台工作线程执行。游戏退出、关闭策略、退出应用或恢复默认时，尝试恢复本次暂停的服务。逐游戏的显式设置优先于全局设置，局中修改也会生效。

只检查以下固定服务，不支持任意名称或强制结束服务宿主：

| 服务 | 功能 |
| --- | --- |
| `PrintNotify` | 打印扩展与通知 |
| `Spooler` | 打印后台处理 |
| `WSearch` | Windows 搜索索引 |
| `WMPNetworkSvc` | Windows Media Player 网络共享 |
| `MapsBroker` | 下载的地图管理 |
| `DiagTrack` | 连接用户体验与遥测 |
| `RetailDemo` | 零售演示 |

这些功能在服务暂停期间可能不可用。不处理内存压缩、`SysMain`、网络、音频、安全或 Xbox 服务；Windows Update 和传递优化仍由原有独立策略管理。

## 原状态与恢复保护

- 入局前已经停止、禁用、不接受停止或存在活动依赖的服务，一律跳过。不会修改服务启动类型。
- 打印组存在任务、忙碌打印机、共享打印机、网络打印连接，或无法可靠读取状态时，跳过。打印检查是状态快照，无法阻止检查后新提交的打印任务。
- 只为本进程成功发出的停止请求建立恢复归属；拒绝、查询失败或不确定的停止结果，不会变成自动启动权限。
- 每个会话只请求停止一次。Windows 或其他软件重新启动服务时，不循环强行停止。
- 恢复前复核服务配置、状态与依赖。发现外部启动、暂停、禁用或修改配置后，放弃恢复；启动前要求依赖已经在运行，不主动启动或修复依赖。复核和实际服务操作之间仍可能有外部状态变化。
- 恢复未完成时保留记录并重试；未确认清账成功前，不开始新的暂停会话，也不允许恢复默认流程抹掉恢复记录。

## 恢复记录

独立使用 `PrevOptionalServicesPausedV1`，不复用旧 `SysMain/WSearch` 策略的记录。记录包含本次系统启动的标识和服务配置指纹，每次写入都读取核对。

| 阶段 | 含义 |
| --- | --- |
| `P` | 已记录停止意图，尚无成功请求的证明 |
| `A` | 停止请求已接受，尚未观察到停止完成 |
| `O` | 已接受停止请求，且已观察到停止完成 |
| `R` | 恢复启动的意图已持久化；启动结果待确认 |

SCM 操作与记录写入不能构成同一个事务。进程异常退出后，`P` 以及结果不确定的 `R` 不会自动重放启动，以免覆盖用户选择；保留记录供后续确认。系统重新启动后清除上次启动的记录，让 Windows 按用户原有的启动配置管理服务。

```powershell
.\build.cmd -b dev Pavise.services.selftest.exe --selftest
.\Pavise.services.selftest.exe --selftest
```

测试使用模拟 SCM、模拟恢复记录和临时设置，覆盖默认关闭、原状态保护、失败重试、异常恢复、开关取消、逐游戏覆盖及恢复默认的保护。自测和性能实验构建会拒绝调用此策略的真实原生适配器；测试不会启动应用界面，也不会停止或启动本机服务。
