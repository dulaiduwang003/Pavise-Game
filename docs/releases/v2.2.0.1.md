# Pavise v2.2.0.1

发布日期：2026-09-03

## 新增

- **英雄联盟增强回归**：游戏库卡片内置，脱壳启动、立即净化、恢复界面、借壳启动、对局真无头、附加层删除。
- **设置页卸载 Pavise 按钮**。

## 改进

- 卸载脚本：先由程序自身按收据还原，再清开机任务、托管电源方案、设置、数据与旧版残留。
- 设置页分标签：极限模式、应用自身、维护、窗口外观。
- 家族后台压制：未观测到渲染的条目不能打开。
- 核显电源方案：独显渲染的机器写平衡。
- 极限档 VBS 关闭不再被 Hyper-V 残留服务键挡住。
- 厂商性能档默认开，不再由档位强制。
- 全局计时器分辨率退出极限自动清单，两项计时器默认关。
- 极限档电源空闲三旋钮因部分机型有提升重新上线。

## 下架

- **显卡频率锁定**：旧版收据启动时解锁。
- **网络收包引离游戏核**：旧版收据启动时写回。

## 升级前注意

- 有线机器升级后首次启动网卡闪断一次。
- 已解锁极限档的机器启动补写 VBS 关闭，重启生效。
