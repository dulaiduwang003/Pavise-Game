# Pavise v2.1.3.1

发布日期：2026-08-28

[审查与验证记录](v2.1.3.1-review.md)

## 新增与调整

- **录屏与覆盖层保护**：复用后台进程快照，不再枚举游戏 DLL 或等待 30 秒。Steam 主程序、网页和覆盖层辅助进程遵守当前游戏的「压制家族后台」选择：默认关闭时保留自动保护，开启后按普通后台规则处理；游戏本体、白名单及其他已确认的保护仍优先。OBS、Discord、RTSS 等独立工具的保护不随该项取消，不按整个安装目录扩散、不增加开关。
- **待机内存清理（ISLC 核心规则）**：放在「优化策略 → 会话附加」，默认关闭，开启前确认。支持列表大小、真正空闲内存和检测间隔三个参数；只有双阈值同时满足才清理待机列表，不裁剪游戏或后台工作集。
- **进入游戏切英文一次**：默认关闭，可逐游戏覆盖。每个新启动的游戏只尝试一次，用户随后切回中文、切出后返回都不会再次干预，退出游戏不恢复输入法。重启 Pavise 不补切已经运行的游戏；缺少英文布局、权限受限或游戏拒绝时跳过。
- **Intel 显卡页签**：与 NVIDIA、AMD 并列，提供可选的游戏期间全局基础低延迟。默认关闭，开启前说明全局范围，仅在驱动报告支持时使用；不包含超频、Boost 或 XeSS 补帧。
- **应用显卡偏好**：放在「显卡 → 通用」。确认同时存在核显与独显时，可选择应用优先使用节能显卡。下次启动应用生效，不迁移或重启运行中的程序，不承诺游戏独占独显。偏好持续保留；移除时仅撤销可确认归属的修改。
- **禁止 CPU 空闲**：回到「优化策略 → 会话附加」，默认关闭，每次开启必须确认。仅用于交流供电下的 Pavise 托管电源方案，退局或拔电后还原本次修改，不改用户自选方案。
- **暂停非必要系统服务**：游戏期间可暂停打印、索引等服务，默认关闭。只恢复本工具本次暂停的服务，原本停止或禁用的服务保持不动。
- **界面与添加游戏**：合并安装记录与正在运行的程序，保留图标和运行状态；统一列表滚动条，完善导航与页面内容过渡。
- **移除旧选项**：移除后备提优 IFEO、逐游戏关闭 CFG 的开关及主动写入。

## 修复

- 修复开启「压制家族后台」时，新出现的同游戏大厅窗口、网页辅助进程可能被普通模式的可见窗口规则误豁免的问题。使用当轮已验证的路径、家族证据和父子身份补齐成员；实际对局渲染器、手动白名单及其他原有保护不变，不把共享启动器的无关子进程一并归为该游戏。
- 修复开启「压制家族后台」后 Steam 仍被覆盖层自动名单放行的冲突。平台主程序及网页、覆盖层辅助进程遵守当前选择，独立录屏和原有安全保护保留；关闭后恢复默认自动保护。
- 修复 AMD 设置、显卡偏好预写入和部分会话策略恢复失败后不再重试的问题。有恢复记录未清理时不再误报完成；合法的待命预写入仍保留。
- 修复 CPU 空闲恢复记录把“准备写入”误当成“已确认写入”的问题，避免在异常恢复时覆盖用户后来设置的值。无法确认的记录继续保留。
- 修复异常启动恢复不检查当前电源计划，以及切换已发出但读回失败时丢失原值记录的问题。当前方案不属于本工具记录的目标时，保留用户选择；当前状态无法核实则保留记录。 本次运行中已完成恢复但清账失败时，只继续清账，不再重复切换方案。
- 修复全局和逐游戏手动选择“全部核心”后，实际仍继承限核策略的问题，并修复部分情况下“应用”按钮不可点击。
- 修复功耗让路熔断后开关被锁住的问题。已开启的项目可关闭；硬件和权限满足条件时，用户可以确认后重新开启验证，全局与逐游戏行为一致。

- 修复辅助键部分修改成功后恢复入口消失的问题；只要仍有恢复记录，界面就保留恢复操作。
- 修复显存保护保存失败仍清除验证停止状态的问题；开启失败保留原状态，取消确认不改变已有选择。
- 修复显卡检测失败或功能不支持时，已开启选项无法关闭的问题。保留真实选择与关闭入口，但禁止开启不支持的功能或档位。
- 修复设置页开机启动状态和白名单被迟到的异步结果覆盖的问题，并防止旧页面回调影响新页面。

- 修复旧服务暂停与传递优化在恢复记录未确认时仍停服务，以及恢复失败后误报完成的问题；停止前先确认记录，失败仍保留恢复责任。

## 升级前注意

- 覆盖层保护识别运行中的已知工具，不证明它正在当前游戏中使用；独立工具仅打开也可能免压制。开启某游戏的「压制家族后台」后，该局 Steam 主程序、网页和覆盖层辅助进程不再获得额外的自动豁免，可能影响平台界面、聊天、浮层或其他依赖功能。需要保留可加入精确白名单；其他游戏已确认保护的同一进程仍会放行。未知、自定义名称或改名工具可用现有精确白名单补充；本项不构成反作弊兼容认证。
- 含已移除逐游戏字段的旧游戏库会走既有的安全恢复、自动清理、提示并退出流程，不保留旧字段兼容。**升级前请备份需要保留的游戏库和配置。** 恢复未完成时不会强制清除恢复记录。
- 新增可选策略默认关闭。内存清理可能增加缓存重新读取和短暂卡顿；禁止 CPU 空闲可能增加功耗、发热和风扇噪声。是否有收益需在同一游戏场景对比。
- 本次 CPU 空闲、旧服务暂停、Intel 低延迟和 GPU 偏好恢复使用明确的写入确认阶段；无法确认归属的相关记录会保留，不强制改写。升级前旧版本留下的旧格式服务暂停记录按旧版本的恢复约定处理：账本内停止的服务会被重新启动并结清记录。若仍提示有待恢复项，应先核实对应系统设置。
- 英文切换使用 Windows 标准请求，不绑定特定输入法，但不保证所有输入法和游戏都会响应；Intel 功能也取决于实际驱动支持。
- 本次采用隔离测试验证逻辑与界面状态，没有启动正常优化运行时、修改实际系统设置或完成全部硬件的实机兼容性测试。
