# Pavise v2.2.1.1

发布日期：2026-09-06

## 新增

- **WeGame 脱壳推广到全部经 WeGame 启动的游戏**：CF、逆战、三角洲等卡片下方与英雄联盟一样有借壳启动开关、脱壳启动与立即净化。

## 改进

- 对局中正在用麦克风的程序不压制，不分档位。QQ、微信、TIM 通话时放行，挂着不说话照常压制。
- KOOK、YY、Oopz、TeamSpeak、Mumble 进保护名单。
- 手柄映射器进保护名单：DS4Windows、reWASD、XOutput、JoyToKey、x360ce、DualSenseX、BetterJoy、AntiMicro、InputMapper、Keysticks。
- 智能档自适应升档改为开关，默认关，策略页与逐游戏页各一行。
- 候选线程提优改为默认关的实验项。
- 游戏高优先级只在核域完整且 CPU 有余量时给。限核、饱和或核域读不出时保持普通优先级，并撤回候选线程提优。
- 电竞档 Intel 大小核线程调度交回系统自动。
- 台式机电竞档核心停泊与笔记本插电同口径放开。
- 功耗让路：读数缺失不进决策，验证期长时间没有证据自动撤回。
- 自动后台节能显卡按程序路径保护可见程序，同一程序的隐藏子进程也不登记。
- 极限电源参数按方案记账，AC、DC 分开备份与恢复，最低处理器状态按平台接口证据决定。
- 反作弊目录补国内平台：完美世界竞技平台、5E、B5 只保护不压制；网易补 NeacClient、OWNeacClient，腾讯补 TP3Helper、ACE-Service64；米哈游驱动进内核识别。
- 卸载 Pavise 收进程序本身：设置页一键完成还原与清理，最后只需删掉 Pavise.exe。
- 运行开销：压制扫描逐进程判定按进程身份记住，白名单评估复用，共享显存查询移到后台。

## 下架

- **缓存预热**：不再在对局稳定后预读游戏资产。
- **Pavise-Uninstall.cmd**：卸载已内置，不再随程序发布。

## 修复

- 反作弊绑核被进程改回且写入被拒后，不再每分钟重试并记异常。本次运行放弃绑核，其余压制照常。
- 游戏库与自动入库的忽略名单改为事务写入，档案被占用时旧档保留，可稍后重试。

## 升级前注意

- 智能档自适应升档与候选线程提优这次都是默认关。之前没有手动设置过的，升级后是关闭状态，要用的在优化策略页打开。
- 缓存预热的开关消失，无需操作。
