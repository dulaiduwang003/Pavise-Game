# Pavise v2.2.2.2

发布日期：2026-09-11

## 新增

- **检测到其他进程调整亲和性 立即纠正**：核心调度页，默认关闭。开启后游戏亲和性被其他进程调整时立即写回所选范围。
- **启动日志记一行各核的能效档与调度评级。**
- **CPU 性能限制的限制标志标出含义**：热限、功率限、域依赖。
- **概览页公告左边加了捐赠入口**：点开是微信二维码，请作者喝杯奶茶。二维码从清单拉，本地有缓存，清单里的 id 没变就不重新下载。

## 改进

- **掌机档不再提供五项**：禁止 CPU 空闲、电源方案空闲策略、缓存预热、显存驻留、核心独占。开着也按关，界面标「预设强制关」。
- **其他进程调整了游戏亲和性时，默认保留其改动**，本局不再落核；改动后不再覆盖独占范围才撤回独占。
- **中断观测的归因证明容忍线程增删**；采集中每轮只核对进程级放置，全量证明三秒一次。
- **智能档自适应升档只在智能档显示**，其它档位整张卡藏起来，逐游戏页同样。
- **窗口化游戏优化的开关只反映 Pavise 自己的操作**，系统本来就开着的显示为关，任何档位都不替用户开。

## 修复

- **中断观测在线程多的游戏里每几秒重开一次采样窗口**，整局出不了实测数据。
- **中断观测开着时 Pavise 自身 CPU 偏高。**
- **手动落核被其他进程改回后只读不写**，读到三次就撤回独占。
- **渲染观测的每一条记录都被日志页归成异常**：采样低于门槛或游戏不在前台都是正常记录，只有真故障才进异常。
