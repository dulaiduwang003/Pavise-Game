# Pavise v2.2.1.5

发布日期：2026-09-09

## 改进

- **核心调度**：从优化策略页独立成单独一页，只保留一张选核图，下方一个「游戏独占这些核」开关。独占范围不再单独选，由所选核心对齐整颗物理核推出；推不出可用范围时开关停用并说明原因。逐游戏配置里只读展示全局设置。
- **核心独占**：放开 CPU 0 所在物理核，是否独占由用户决定，唯一限制是独占之外至少留两颗完整物理核。默认全选时会占满全部物理核导致开关停用，选核区新增「留出系统核」快捷键，从末尾整核开始让到刚好成立；说明文字给出总核数、已选核数与还需让出的颗数。
- **核心独占**：按全局一份生效，逐游戏配置里只读显示当前独占摘要；不支持的系统在页面上直接说明要求。
- **显存驻留**退出极限档强制清单，默认关闭不变，各档位都由用户自己决定开不开。
