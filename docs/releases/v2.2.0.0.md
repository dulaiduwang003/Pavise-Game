# Pavise v2.2.0.0

发布日期：2026-09-02

## 新增

- **显卡频率锁定**：对局中 NVIDIA 钉在最高频率，AMD 抬高最低频率。台式机上电竞与极限档强制，退局解锁。
- **笔记本厂商性能档**：Lenovo Legion 与 ASUS ROG 对局中切到性能档，退局切回。电竞与极限档强制。
- **NVIDIA 窗口化 G-SYNC**：只对全屏生效的 G-SYNC 对局中扩到窗口化，退局写回。
- **关闭 Intel Endurance Gaming**：电池供电不再封顶帧率。默认关，极限档强制。
- **暂停自动维护**：对局中挂起 Windows 自动维护。默认开。
- **逐游戏 DPI 兼容层**：与全屏优化兼容层并存。
- **有线跃点修复**：有线网关在线但默认路由走无线时改回自动跃点。体检页有修复入口。
- **计时器精度 0.5 毫秒档**。
- **疑似恶意进程提醒**：无窗口后台进程长时间占满核心或自行解除核心限制时，记异常日志并弹气泡提示可能感染挖矿病毒。
- **系统环境页三项持久项**：可变刷新率优化、关闭网卡链路节能、AMD Smart Access Memory。备份后写入，可还原。
- **托管电源方案十二项**：USB3 链路电源管理、核显电源方案、可切换显卡策略，九项一类核旋钮。

## 改进与修复

- 日志分级：环境限制类记录改为警告，只有真正的功能故障计入异常。
- 卸载脚本：删除收据前先按收据还原系统改动，托管方案按现名匹配。
- 极限档强制项加硬件资格门：低延迟强制降为开，工作集修剪加内存门，保留核八物理核起，禁止 CPU 空闲 AMD 不提供，缓存预热跳过 NVMe，硬件调度下不写显卡降级，蓝牙输出跳过音频低延迟。
- 撤掉极限档电源空闲组的空闲检查周期，它每局报一项写入失败。
- 托管电源方案改名为"由软件调度 加机器码"，去掉 PG 前缀。
- 锁定标签统一为预设强制开、预设强制关、本机不适用、系统已开启。

## 升级前注意

- 台式机电竞与极限档强制锁频，显卡空闲功耗和温度会上升。
- 疑似恶意进程提醒报的是"可能"，先在任务管理器核对文件位置再查杀。
- 驱动与厂商接口项只在对应硬件上出现，未在全部硬件上实测。
