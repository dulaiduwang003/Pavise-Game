# Pavise v2.1.3.3

发布日期：2026-08-31

## 新增与调整

- **缓存预热（实验）**：位于「优化策略」，默认关闭、开启前确认，可逐游戏覆盖。对局稳定约一分半后，以最低磁盘优先级的线程顺序读取游戏目录中最近访问过的大文件（最多 2 GB），使其进入系统待机缓存，后续换图与素材加载可命中内存。纯读取，无残留；仅在交流供电、可用内存充足且游戏盘为固态时执行，机械硬盘不参与；本局待机内存清理生效时自动跳过。本机实测：预热后二次读取约快 2.6 倍（高速 NVMe；SATA 固态收益更大）。
- **内存驻留（实验）**：显存驻留在系统内存侧的对应功能。物理内存持续吃紧（≥85%，连续三次采样）时，为游戏渲染进程锁定硬性工作集下限（工作集的 80%，上限为物理内存的三分之一），使系统修剪不再回收游戏的内存页。写入回读核实，验证失败则撤销并停止尝试，退局还原原配额，异常退出后下次启动补撤；物理内存低于 16 GB 的机器不参与。
- **对局单屏（实验）**：对局中切换为仅主屏（与 Win+P 相同的拓扑切换），避免误点副屏导致游戏失焦，同时省去副屏的桌面合成开销；退局切回，各屏参数由 Windows 显示数据库恢复。快照先行、回读核实、异常退出后下次启动补切；副屏中途断开时按单屏收尾；远程会话既不切换也不结算。切换瞬间会短暂黑屏，副屏窗口位置可能变化，不建议在直播或副屏挂载工具时开启。
- **关闭网卡中断合并**：系统环境页持久项。仅写入物理有线网卡的标准化开关（*InterruptModeration），无线与虚拟网卡不在范围内；收包立即触发中断，网络延迟更低且更稳定，重启生效、备份可还原。代价：高吞吐时 CPU 占用略有上升。
- **智能档自适应升档**：智能档内置，与智能保帧、智能让位同级，无需开关。常态保持智能档的低噪省电策略；CPU 持续饱和（90% 以上超过十秒，带滞回）时临时启用专注档的压制范围与电源激进列，稳定两分钟后自动降回，一局最多升档三次，退局全部复原。升档期间"正在使用的程序不参与压制"暂不适用；不需要该行为可改用自定义档。
- **自动中断编排（实验）**：中断页开关，开启前明确告知将自动写入注册表。多局实测判定某设备与游戏核冲突后，自动将其中断钉到游戏核之外（目标 = 实测系统核 ∖ 游戏核），每台设备写入收据、重启后生效；随后累计三局按同一判定标准自动验收，冲突消失则保留，未消失则按收据回滚并对该驱动版本停止尝试。一次最多 3 台；多队列网卡、存储控制器、显卡与音频设备、键鼠链路不在范围内，已手动钉核的设备不接管；关闭开关立即还原全部自动改动。需同时开启对局中断观测。
- **自动后台节能显卡**：对局稳定后检测一次，将仍在游戏渲染卡上执行 3D 负载的后台程序登记为下次启动使用节能显卡。带可见窗口的程序（副屏播放器、浏览器）不在范围内；占用率取连续三轮采样的最小值，排除瞬时尖峰；每局最多 2 个，每个程序仅自动登记一次，移除后不再自动加入。
- **功耗让路升级**：无法读取 RAPL 功耗的笔记本降级使用平台频率验证（EPP 释放功耗的途径即为降频，频率无变化即判定该机制无效并停止尝试），两级验证分别记账；验证通过后不再一让到底——持续监测 30 秒滚动窗口，瓶颈移回处理器即归还预算，显卡再次饱和可重新让出，一局最多三次，滞回带防止振荡。
- **对局中断观测降本**：观测会话仅订阅 DPC 事件（台账与判定只采用 DPC 证据），事件量约减半；证据饱和（本次开机的合格局数达到判定窗口）且无待验收钉核后，按预算每四局观测一局，重启或拓扑变化自动恢复全量，局中手动切换观测开关立即豁免预算。
- **运行日志记录开关**：位于日志页底栏。关闭后不再写入新记录，已有内容保留、可查看可清空；崩溃转储不受影响。
- **深度调优更名为高级**：入口、标题与相关提示同步。
- **体检结论区收紧**：仅保留需要处理的项，全部通过时明示"没有需要处理的项"。
- **界面文案全面修订**：去除口语与自解释表述，统一术语。

## 修复

- 修复功耗让路验证窗恰逢过场或加载屏时，功耗自然回落被误判为未生效而停止尝试的问题；现按 CPU 负载漂移判定为无法判定，退回但不停止尝试，下局重试。
- 反作弊压制移除温和 / 均衡 / 强力三档选择，构成固定为扫描安全：低于正常的 CPU 优先级、极低磁盘 IO（扫盘是主要伤害）、小核限频；不压最低优先级、不封定时器精度、不降内存页优先级。ACE 等扫描型反作弊扫描游戏内存时会挂起游戏线程，恢复时机取决于扫描进程何时跑完；把它压到最低优先级并封定时器，CPU 满载时它几乎分不到时间片，短暂卡顿因此拖成数秒卡死（表现为 CPU 100% 游戏卡死）。旧版选过的档位不再读取。
- 修复"清除全部配置"可能被无法确认归属的恢复记录无限期拦住的问题（表现为只还原了系统环境改动、设置未被清除）。此类记录现按"仅移除记录"结清并保留系统现状；其余还原失败仍保留恢复记录等待重试，失败弹窗会列出拦住重置的具体项目。
- 修复游戏提优日志把反作弊拒绝写入和磁盘 IO 优先级未被接受误记为"提优失败"的问题；前者按反作弊保护游戏的预期结果记录并点名反作弊，后者按提示记录且不影响已生效的调度优先级。
- 修复启动欢迎窗不显示在任务栏、被其它窗口遮住后无法找回的问题。
- 修正若干界面细节：高分屏下顶栏控件边框对齐、反作弊卡片说明截断、模式选择弹窗描述截断。

## 升级前注意

- 除智能档自适应升档（内置行为，退局自动复原）外，本版新功能默认关闭，开启前均有确认说明。每一步写入均尽量回读核对，验证失败一律撤销并停止尝试，重新开关即重新授权尝试。
- 自动中断编排会自动修改设备中断亲和注册表项（每台设备写入备份收据），并依赖对局中断观测提供证据；关闭观测将连带关闭编排并还原其钉核。
- 关闭网卡中断合并为持久改动（重启生效），非游戏时段同样承担更高的中断率；可随时在系统环境页还原。
- 对局单屏在拓扑切换瞬间会短暂黑屏，对独占全屏处理不佳的游戏可能造成干扰；不建议在直播或副屏挂载工具时开启。
- 内存驻留在内存持续紧张时会使其他后台程序更早被换出；缓存预热与待机内存清理互斥，两者同时开启时预热自动让位。
- 本次采用隔离测试验证逻辑与状态机（50 套自测全部通过），并经三轮对抗式代码审查；未在正常优化运行时修改实际系统设置，也未完成全部硬件的实机兼容性测试。各功能的实际收益请在同一游戏场景下对照评估。
