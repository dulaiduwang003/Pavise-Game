# Pavise 实现与维护

当前开发分支为 `dev`，未发布构建统一使用 `3.2.0.2`。已发布版本记录保留在发布说明和 Git 历史中。

## 运行策略与配置

智能、电竞是对局运行策略；默认、极限是批量配置预设。预设由 `ConfigurationPresetCatalog` 定义，`ConfigurationPresetCoordinator` 串行应用，`ConfigurationPresetRuntime` 读取保存状态。选择预设不立即写入，点击应用后才执行。硬件不支持或状态未知时按功能自身的准入规则处理。

`GameMode` 管理游戏识别、对局生命周期与动作协调。`PolicyCatalog`、`PerformanceActionCatalog` 和各功能模块定义可用项。完整目的、使用条件和当前配置由 `AiTuningFeatureCatalog` 汇总；增加或下线功能时应同步目录与覆盖检查。

## 电源与实验室

托管电源由 `ManagedPowerPreset` 和 `PowerPlan.Presets` 按平台、架构与场景自动选择，掌机沿用移动端 CPU 规则；工作站、多处理器组和多插槽统一使用通用计划，不再提供掌机适配开关。资源及恢复边界见[托管电源说明](MANAGED-POWER-PRESETS.md)。日常电源计划、用户已有偏好和恢复记录分别维护，不能把来源数据拼接成未定义的通用方案。

实验室功能由 `LaboratorySession` 的单个工作线程执行。界面和游戏扫描发布意图，动作后端负责能力检查、原值记录、写入核验及恢复。守护关闭、对局切换与退出时应阻止过期任务重新应用。

## 后台治理与恢复

后台治理执行器分别维护压制、冻结、限额和服务暂停状态。概览计数仅使用已确认执行且仍有效的记录，并按进程创建时间区分 PID 复用；关闭守护或结束对局后清除显示。

系统写入与用户偏好分开保存。写入前登记恢复意图，写入后回读确认；恢复失败保留记录，外部后写值按各模块的所有权规则处理。故障隔离规则见[执行动作故障隔离](Action-Failure-Isolation.md)。

## 界面与更新

`PanelForm` 及其分文件维护工作区。可复用控件共用尺寸、字体、交互和弹出层契约，见[UI 组件说明](UI-COMPONENT-LIBRARY-20261012.md)。异步回调应验证当前窗口、会话和请求身份。

软件内更新的签名、下载、替换与失败恢复机制见[更新说明](SELF-UPDATE.md)。发布私钥保存在仓库外；客户端只携带验签公钥。

## 构建与验证

运行 `build.cmd -b dev <output.exe>` 编译并核对构建身份。使用独立输出路径，避免覆盖正在运行的程序。构建和验证不自动启动或重启 Pavise。

当前回归入口及隔离方式见[测试说明](../tests/Official3106/README.md)。测试结果以对应源码快照的输出为准，不沿用旧试验的通过数量。
