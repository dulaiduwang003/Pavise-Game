# 掌机相关改动：十轮复核与修复

日期：2026-09-08；版本：2.2.1.4。范围是近期的游戏高优先级恢复、功耗让路放宽、Intel 核显电源策略，以及恢复的缓存预热。工作区其他已有改动不代表都在本报告范围内。

## 复核记录

十轮使用不同入口、故障轨迹和交叉审查，并非把相同测试重复十次。发现问题的轮次保留发现记录，修复后再复查及运行全量隔离测试。

| 轮次 | 范围与方法 | 发现及处理 |
| --- | --- | --- |
| 1 | 正常开局 → 首次提优成功 → 缓存预热；调用实际记账入口 | 预热原先依赖会被清零的首次提优计时戳，改用整局稳定的独立会话编号。覆盖同局 PID 交接、同身份新局、直接换游戏。 |
| 2 | 独立检查游戏档案学习路径、检测结果发布间隙 | 同档案换安装目录或 renderer 路径时旧回调仍有效；现在任务键及准入同时核对当前库与检测路径，新路径及时取消旧等待。 |
| 3 | 缓存取消、排空、锁顺序与预算 | 等待中取消可以同 key 重试；读取已经开始后保留尝试记录，避免内存压力反复变化时重读并重置预算。核对 G→H→G、大小写及退出排空。 |
| 4 | 原始功耗误熔断轨迹 | t22/24/26 验收样本后缺测到 t68，t70 回来的是另一场景；现在先处理证据间隙，归还 EPP 并判无法确定，不写持久停用标记。 |
| 5 | 时间边界和周期稀疏证据 | 检查 14/15、19/20、29/30、59/60 秒及时间回拨；修复部分功耗读数缺失时观察过早退出、周期稀疏验收误停用。首次验收总时间仍最多 60 秒。 |
| 6 | 第二位审查者检查配对基线及连续性 | 稀疏观察的旧场景数据也会污染基线；将观察中断标记带入负结论保护。完整新观察窗清标记，连续负结果仍停用，正常 3 秒抖动不误判中断。 |
| 7 | 采样 → 决策 → 写入/还原，generation 和恢复回执 | 无效 GPU 读数仍送入状态机；旧 generation 不可写；无法确定走还原。恢复失败保留原始值回执，后续停止重试，不覆盖快照；不会重新激活用户已切离的方案。 |
| 8 | 档位、默认策略、实时开关和跨功能边界 | 修复运行中功耗让路失去资格仍继续、切掌机后残留 lane。核对 Intel 仅确认唯一核显的掌机档取性能值，CPU 调度仍自动；缓存默认关且让位待机清理，Extreme 不强开缓存。 |
| 9 | 测试隔离、编译、三语文档和全量回归 | 隔离入口不走正常应用运行时，电源与线程写入使用 mock。首次整合 75 组通过 74 组，旧 UI 测试的 5 秒人工基线被新连续性规则拦住，修正为实际 2 秒节奏并保留负结论及 UI 断言。 |
| 10 | 非作者最终交叉检查缓存、Intel、lane、功耗任务交接 | 发现先发布新准入再停止旧任务的竞争窗口；已改为旧代停止前保留旧授权，切换目标先拒绝旧代。同 PID 配置失效会停止旧状态，健康同 PID 不重启。受控栅栏用例检查旧代写入为零，最终独立复查通过。 |

## 关键行为

- 高优先级恢复旧规则，限核、CPU Sets 或未知核心域不会单独阻止提优。CPU 饱和且无符合当前策略的已生效 lane 才回 Normal。
- 进入掌机档、关闭 lane 或禁止写入时清收旧 lane；失败可重试，残留不再构成饱和豁免。
- 功耗让路仅累计完整配对基线，允许加载和短暂缺测；不连续证据导致的负结果会还原，但不判定为硬件永久无效。
- 功耗任务运行中和写入前检查当前有效偏好、档位、交流供电及活动托管方案。普通/掌机的全局默认为关；极限档原有强制项规则保留，不能把全局关误写成所有模式都关。
- Intel 核显电源策略属于核显驱动项，独立于 CPU 的平衡方案与大小核调度。仅掌机档且启动清单确认唯一显卡为 Intel 核显时请求性能值；其他拓扑继续平衡。

- 隔离自测编译成功；完整回归 **75 组通过 75 组，失败 0 组**，进程退出码 0。组数不是单条断言数。
